# DroneLiDAR-BIM: Автоматизированный экспресс-аудит выработки и земляных масс по данным БПЛА-LiDAR

Программный комплекс оперативного маркшейдерского контроля строительных и горных объектов ПАО «Газпром». Разработан для обработки сверхплотных облаков точек лазерного сканирования с промышленных БПЛА-комплексов (**DJI Matrice 350 RTK + Zenmuse L2**).

Обеспечивает полный цикл: от чтения нативных файлов `.las 1.4` непосредственно с борта дрона до формирования юридически значимого маркшейдерского протокола (РД 07-603-03 / СП 11-104-97) за 60 секунд.

---

## 🎯 Решаемые задачи в структурах Газпрома
1. **Строительный аудит кустовых площадок и компрессорных станций**: Оперативный контроль фактического объема отсыпки песка/щебня и выемки котлованов против проектных отметок.
2. **Исключение приписок подрядчиков**: Независимый объективный подсчет объемов в целике, объемов с учетом разрыхления ($K_р$) и массы перемещенной породы в тоннах.
3. **Импортозамещение зарубежного «тяжелого» софта**: Замена связок Carlson Mining, Leica Infinity и Bentley ContextCapture на компактное, быстродействующее отечественное решение без закупки дорогостоящих рабочих станций.

---

## ⚙️ Архитектурные особенности и стек
- **Язык разработки**: C# (.NET 8.0) + SIMD / Linear Algebra (`MathNet.Numerics`).
- **Спецификация данных**: Нативная поддержка стандарта ASPRS LAS 1.4 (форматы точек 6, 7, 8) со считыванием меток мультиэхо Zenmuse L2.
- **Математическое ядро**:
  - *PMF-фильтрация*: Прогрессивный морфологический фильтр для очистки рельефа от временных строений, растительности и карьерной спецтехники (буровые станки, самосвалы, экскаваторы).
  - *Защищенный RTK-ICP*: Выравнивание облаков точек строго по стабильным поверхностям вне контура работ с пороговым контролем аномалий (не допускает искажения абсолютной RTK-привязки).
  - *2.5D DEM Grid с интерполяцией разрывов*: Высокоточный расчет баланса выемки (+Cut) и насыпи (-Fill).
  - *Оценка погрешности*: Расчет средней квадратической погрешности (СКП / RMSE) высотного положения по контрольным стабильным участкам.
- **Визуализация (4D)**: Three.js (WebGL), стриминг геодезических данных через многоуровневое октодерево (Octree LOD) без просадки FPS в браузере.
